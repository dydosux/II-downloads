# II — переносимое приложение Windows

## Оценки и автоматическое обучение

В фотолаборатории добавлен раздел «Материалы и фоновое обучение». Папка
`data/learning/materials` принимает изображения с одноимёнными TXT-описаниями.
Оцените материалы и результаты кнопками «Хорошо / Плохо», при необходимости
оставьте замечание. Только одобренные примеры используются для обучения LoRA.
Настройте активность, минуты на цикл и включите автоматический запуск.
Исходная модель сохраняется; доступна кнопка отката адаптера.
Подробная инструкция: [LEARNING.md](LEARNING.md).


## Фотореалистичные персонажи

В фотолаборатории выберите «Фотореализм» и нажмите «Создать фото».
Доступны быстрый и тщательный (два прохода) варианты, а также зерно для
сравнения результатов. Без загруженного изображения старые фото автоматически
не подставляются. Художественный этюд взрослой фигуры предназначен для
неэротической наготы вымышленного персонажа 30 лет и создаётся только с нуля.
Подсказки на английском позволяют точнее описать детали, которых нет в русском
словаре приложения. Стили и зерно относятся к кнопке «Создать фото»;
«Выполнить задание» использует прежний режим поиска и памяти примеров.

Это настройки генерации на имеющейся SD 1.5, а не новые обученные веса.
Ошибки анатомии и сходства возможны; больше шагов не гарантирует лучший снимок.


Распакуйте **всю папку** в доступное для записи место и дважды нажмите `II.exe`.
Python и библиотеки уже находятся внутри. Кнопки окна открывают локальный чат,
настройки нагрузки и фотолабораторию в браузере. Закрытие браузера не завершает
приложение; закрытие окна II останавливает запущенные им серверы и их обучение.

Данные, результаты и обучение сохраняются в `data`, веса — в `checkpoints`.
Для завершения обучения с сохранением используйте кнопку остановки обучения
в чате перед выходом из приложения. Для переноса своих данных копируйте всю
папку приложения. Журналы запуска находятся в `data/logs`.

Сборка предназначена для Windows x64. При совместимой видеокарте NVIDIA и
драйвере используется CUDA, иначе доступен CPU. CUDA-сборка не использует
видеокарты AMD/Intel для вычислений. Скорость зависит от памяти и оборудования.
Для работы нужен системный Microsoft Visual C++ Runtime, если его ещё нет.
ComfyUI запускается и устанавливается отдельно.

В чистую сборку не входят ваши фотографии, переписка, обучающие примеры,
Telegram-токены и настройки. Базовая сборка без `-IncludeWeights` не содержит
обученных весов. Сборка с `-IncludeWeights` переносит существующие веса модели
и локальный кэш SD 1.5; состав указан в `BUILD.json`.
Если веса не включены, генерация фото может загрузить SD 1.5 при первом обращении; после загрузки
веса хранятся локально. Доступ к поиску и загрузке моделей требует интернета.

## Сборка из исходников

Предварительно установите рабочее окружение через `install.ps1`.

```powershell
.\scripts\build_portable.ps1 -EstimateOnly
.\scripts\build_portable.ps1
```

Результат: `dist/II-portable/II.exe`. Передайте адресату весь каталог, например
упаковав его в ZIP. Одного `II.exe` недостаточно.

Скрипт использует установленный Python, его стандартную библиотеку, Tcl/Tk и
только зависимости приложения. Нужен компилятор C# из .NET Framework Windows.
Никакие пакеты при сборке не скачиваются. Каталог результата должен быть новым;
существующая сборка никогда не перезаписывается.

```powershell
.\scripts\build_portable.ps1 -OutputDir dist\II-with-models -IncludeWeights
```

`-IncludeWeights` отдельно разрешает включить `ii.pt`, `tokenizer.json`,
`photonet.pt` и файлы модели SD 1.5. Такие веса могут отражать ваши обучающие
данные; используйте этот параметр только для модели, которую хотите передать.
Обучающие наборы и личные настройки не копируются даже с этим параметром.

Приложение нужно проверять на целевом ПК: переносимость сборки не гарантирует
совместимость любого драйвера видеокарты или одинаковую скорость обучения.
