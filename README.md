## Установка

1. Скачайте и запустите `II-Setup.exe`.
2. Выберите новую папку на диске, где свободно примерно 38 ГБ.
3. Нажмите «Установить». Загрузчик сам скачает и проверит части сборки, распакует приложение и создаст ярлык.

Загрузка занимает около 16,49 ГБ, установленное приложение — около 20,12 ГБ. В сборку включены Python, библиотеки и файлы моделей. После успешной установки загруженные части можно автоматически удалить.

При обрыве соединения запустите установщик ещё раз и выберите ту же папку: скачивание продолжится. Можно выбрать от одного до четырёх потоков. Скорость зависит от вашего подключения к GitHub.

## Требования

Windows 10/11 x64, .NET Framework 4.8 и Microsoft Visual C++ Runtime. Для CUDA нужна совместимая видеокарта NVIDIA и её драйвер. При отсутствии CUDA приложение может использовать CPU; генерация будет медленнее. ComfyUI и Wan 2.1 T2V 1.3B включены в сборку. Для проверенного режима видео рекомендуются NVIDIA с 6 ГБ VRAM и 32 ГБ RAM.

Установщик не подписан сертификатом издателя. Контрольные суммы файлов находятся в `SHA256SUMS.txt` соответствующего выпуска. Установщик содержит собственные SHA-256 частей и проверяет их перед распаковкой.

## Видео Wan

В чате выберите «Видео — Wan 2.1 1.3B» и напишите описание сцены. Доступна короткая проба. На GTX 1060 6 ГБ проверены видео 832 × 480: 0,5 секунды за ~8 минут и 1 секунда за ~17 минут. Результат воспроизводится в чате и доступен для скачивания; статус восстанавливается после обновления страницы.

Подробности: [видео Wan](docs/wan.md).

## Использование

Запускайте ярлык II+ или `II.exe` в выбранной папке. Ваши материалы и результаты сохраняются в папке `data` установленного приложения. Публичная сборка не содержит личных журналов и истории обучения автора.

Подробнее: [переносимое приложение](docs/PORTABLE.md), [материалы и обучение](docs/LEARNING.md), [устройство установщика](docs/INSTALLER.md).

Модель Stable Diffusion 1.5 распространяется на условиях [CreativeML Open RAIL-M](docs/SD15-LICENSE.txt). Лицензии библиотек включены в сборку. Исходный код установщика находится в `scripts/Installer.cs`.
